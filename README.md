# AI Builder для Geometry Dash

Минималистичная тёмная панель в редакторе: круглая кнопка **AI**, поле запроса,
**Gameplay / Decor**, **Generate**. Во время запроса Generate становится **Cancel**.
Мод общается с локальным Python-мостом, который вызывает ваш CLI.

Поддерживаются **GD 2.2081**, **Geode 5.11.1+**, Windows x64 и Android arm64.
Actions использует последний стабильный SDK (`sdk: latest`) и C++23.
В актуальном build-geode-mod цель Windows называется `Win64`; имя задания — Windows.

## Скачать и установить .geode

1. Откройте [Actions → Build](https://github.com/siggmaez/GD-AI-builder/actions/workflows/main.yml).
2. Выберите успешный запуск последнего коммита. Дождитесь зелёных Windows,
   Android64 и bridge-tests.
3. Внизу, в Artifacts, скачайте `gd-ai-builder-Windows` или
   `gd-ai-builder-Android64`. Для скачивания артефактов нужен вход в GitHub.
4. Распакуйте ZIP. Внутри находится один `siggmaez.gd-ai-builder.geode`.
   Сам файл `.geode` распаковывать не нужно. Установите версию своей платформы.
5. Закройте игру, положите `.geode` в папку модов и запустите игру снова.

**Windows:** `<папка Geometry Dash>\geode\mods\`, например
`C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash\geode\mods\`.

**Android, стандартный Geode Launcher:**
`/storage/emulated/0/Android/media/com.geode.launcher/game/geode/mods/`.
Если ваша версия лаунчера использует другое расположение, откройте его папку
игры/модов средствами лаунчера и найдите `geode/mods`.
[Инструкция Geode с путём Android](https://github.com/geode-sdk/docs/blob/main/getting-started/create-mod.md).

## Мост на ПК и вход через ChatGPT

Установите Python 3.10+ и Node.js LTS. Скачайте исходники этого проекта;
рядом с `bridge.py` обязательно должна быть папка `resources` с белым списком.
Зависимостей Python из pip нет.

В PowerShell, из папки проекта:

```powershell
npm install -g @openai/codex
python bridge.py --login
python bridge.py --auth-status
python bridge.py
```

`--login` запускает официальный `codex login`: выберите вход через ChatGPT в
браузере. Если браузерный вход недоступен:

```powershell
python bridge.py --login --device-auth
```

При необходимости включите device-code login в настройках безопасности аккаунта
ChatGPT. Доступ к Codex и лимиты зависят от аккаунта/тарифа.
Учётные данные хранит официальный CLI на машине с мостом; мод их не читает и не
отправляет. Повторный вход при каждом запуске моста не нужен.
[Официальная документация входа](https://learn.chatgpt.com/docs/auth).

Настройка CLI в моде по умолчанию — `codex`. Для Claude или Gemini установите
соответствующий CLI, войдите в него через терминал и выберите `claude` / `gemini`
в настройках мода. Мост вызывает только эти три фиксированные команды.

Мост по умолчанию слушает `127.0.0.1:8765`. Для игры на том же ПК оставьте URL
`http://127.0.0.1:8765`.

### Телефон подключается к мосту на ПК

ПК и телефон должны быть в одной локальной сети. На ПК:

```powershell
$env:BRIDGE_HOST = "0.0.0.0"
python bridge.py
```

Разрешите Python входящие подключения в частной сети Windows. В настройке мода
Bridge URL укажите `http://<локальный-IP-ПК>:8765`. `127.0.0.1` на телефоне
означает сам телефон. Не выставляйте мост в интернет: у него нет сетевой авторизации.
Остановить мост можно Ctrl+C в его терминале.

## Мост в Termux на Android

Установите Termux из доверенного актуального источника. В Termux:

```sh
pkg update
pkg install python nodejs-lts git
git clone https://github.com/siggmaez/GD-AI-builder.git
cd GD-AI-builder
npm install -g @openai/codex
python bridge.py --login --device-auth
python bridge.py --auth-status
python bridge.py
```

В игре выберите CLI `codex` и Bridge URL `http://127.0.0.1:8765`.
Оставьте Termux работающим; отключите для него агрессивную экономию батареи,
если Android останавливает мост при переключении в игру.
Если npm не установил Linux arm64-бинарник Codex или песочница CLI не поддерживается
на вашем Android, используйте мост на ПК по Wi-Fi. Установка и запуск CLI в Termux
на реальном телефоне здесь не проверялись.

Переменные окружения (необязательны):

```sh
BRIDGE_CLI=claude BRIDGE_PORT=8765 python bridge.py
```

Выбор CLI в запросе мода имеет приоритет над `BRIDGE_CLI`.

## Работа в редакторе

1. Откройте уровень и нажмите AI. Под полем запроса появится **Bridge online**
   или **Bridge offline**. Проверка доступности имеет таймаут 4 секунды;
   она показывает доступность HTTP-моста, а не наличие подписки или входа в CLI.
2. Выберите Gameplay или Decor, напишите запрос и нажмите Generate.
3. **Gameplay** создаёт участок после последнего объекта, в пределах следующих
   3000 единиц по X и 0–3000 по Y. Мост получает точные границы.
4. **Decor** использует границы выделенных объектов с отступом 60 единиц.
   Без выделения используется видимая область редактора, ограниченная размером
   6000×6000. Если в области нет объектов, генерация не начинается.
   В контекст отправляются до 300 существующих объектов; они не изменяются.
5. Все добавленные объекты записываются в **одну операцию undo**.
   Ctrl+Z на ПК или Undo в редакторе на телефоне должны убрать генерацию целиком.
6. Cancel или закрытие панели отменяют HTTP-запрос и исключают применение
   его запоздалого ответа. Уже запущенный процесс CLI на мосту может продолжать
   работу до завершения/таймаута и расходовать лимит аккаунта.

## Настройки Geode → AI Builder

| Настройка | Назначение |
| --- | --- |
| Bridge URL | HTTP-адрес машины с `bridge.py` |
| CLI | `codex` (ChatGPT), `claude`, `gemini` |
| Object limit | Максимум новых объектов: 1–1500, по умолчанию 300 |
| Panel opacity | Непрозрачность фона: 80–255, по умолчанию 240 |

Панель масштабируется под размер экрана. Интерфейс оставлен компактным и тёмным.

## Проверки и ошибки

Мод независимо от моста проверяет JSON, конечность чисел, белый список ID,
границы области, масштаб 0.5–2, поворот −360…360 и лимит объектов. Некорректные
записи пропускаются. В Decor запрещены игровые блоки, шипы, пады, орбы и порталы.
Белый список общий для мода и моста: `resources/object-whitelist.json`.
Не заменяйте его диапазоном вроде `1007+`: там есть триггеры, а не только декор.

Мост извлекает JSON из текста и блоков `json`, повторяет невалидный ответ ровно
один раз и ограничивает суммарное ожидание CLI 150 секундами. Мод ждёт до 180 секунд.
`GET /health` отвечает даже во время генерации. Одновременно допускаются два CLI-запроса.

| Сообщение | Что сделать |
| --- | --- |
| Bridge offline / request timed out | Запустить мост, проверить URL, Wi-Fi и firewall |
| CLI not logged in | Выполнить вход выбранного CLI в терминале на машине с мостом |
| Selected CLI not installed | Установить CLI и перезапустить мост с правильным PATH |
| Invalid JSON after retry | Упростить запрос; модель дважды не вернула допустимый JSON |
| CLI timed out | Уменьшить запрос или проверить доступность сервиса CLI |
| Bridge busy | Дождаться завершения предыдущих процессов |
| Missing or invalid object whitelist | Переустановить полный `.geode` с ресурсами |

Проверить мост вручную: откройте `http://127.0.0.1:8765/health` в браузере.
Запустить тесты:

```sh
python -m unittest discover -s tests -v
```

## Что требует проверки в игре

Компиляция и тесты моста не заменяют запуск GD. На реальном ПК/телефоне нужно
проверить расположение и нажатие AI, ввод текста, закрытие/Cancel, масштаб панели,
выделение и область Decor, вид объектов, единый undo/redo и сохранение уровня.
Шаблоны расстояний в промпте не гарантируют проходимость сгенерированного геймплея.
Если случится сбой, пришлите описание, шаги и лог Geode из папки `geode/logs`
или `geode/crashlogs` рядом с папкой mods.
