# AI Builder · Geometry Dash 2.2081

Geode-мод для Windows x64 и Android arm64. Интерфейс **на английском**, кнопки и
подписи используют штатный **Pusab (`bigFont.fnt`)**. Ввод и ответы ИИ поддерживают
русский, включая ё/Ё, благодаря отдельному встроенному Unicode-шрифту.

## Скачать мод

Откройте [Releases](https://github.com/siggmaez/GD-AI-builder/releases/latest):

- `AI-Builder-Windows.geode` — Steam/Windows;
- `AI-Builder-Android64.geode` — Android arm64;
- `AI-Builder-Bridge.zip` — мост, страница входа и ресурсы;
- Source code — полный исходный код соответствующего релиза.

Закройте игру и положите `.geode` в папку модов. Не распаковывайте сам `.geode`.

Windows: `<Geometry Dash>/geode/mods/`.

Обычный Android Geode Launcher:
`/storage/emulated/0/Android/media/com.geode.launcher/game/geode/mods/`.
Если сборка лаунчера использует другой путь, откройте папку игры/модов через него.

Также доступны [Actions](https://github.com/siggmaez/GD-AI-builder/actions/workflows/main.yml):
выберите зелёный запуск и скачайте `gd-ai-builder-Windows` / `gd-ai-builder-Android64`.
Каждый архив содержит один `.geode`. Сборка: SDK latest (минимум Geode 5.11.1),
GD 2.2081, C++23. Windows называется `Win64` в актуальном build-geode-mod.

## Как пользоваться

- Перетаскивайте круглую **AI** мышью или пальцем. Позиция сохраняется.
- **Ask AI** отвечает текстом; **Generate** строит участок. Чат слева, схема области справа. Окно занимает не более 82% ширины и высоты экрана; редактор виден вокруг него.
- **Chats** открывает сохранённые чаты, **New chat** создаёт новый. История этого мода
  хранится локально; последние 20 сообщений передаются CLI как контекст. История
  настольного Codex сюда не переносится.
- Кнопка модели над чатом или **More → Model** показывает модели из кеша установленного Codex CLI. Можно ввести имя
  вручную или выбрать **CLI default**. Доступность зависит от вашего аккаунта;
  мост не переключает модель незаметно при ошибке.
- **+** открывает системный выбор PNG/JPEG до 5 МБ. **Reference** переключает
  предпросмотр фото/области. Повторное нажатие **+** позволяет заменить или убрать фото. Оно отправляется только
  со следующим сообщением, а в истории сохраняется отметка без копии изображения.
  Фото пока поддерживаются только Codex CLI и моделями с обработкой изображений.
- Кнопка **Area** переключает View / Selection / Extend. **View** ограничивает построение видимой рабочей областью над панелью инструментов.
  **Selection** использует точные границы выделения; если выделения нет, берётся View.
  При первом открытии с выделением автоматически выбирается Selection.
  **Extend** явно разрешает новую секцию после конца уровня, с размерами из настроек.
- **Gameplay** и **Decor** работают внутри выбранной области. Полный прямоугольник
  каждого объекта проверяется в игре: выходящие за границы объекты пропускаются.
  Во время запроса область фиксируется и подсвечивается в редакторе.
- Закрывайте меню крестиком: запрос продолжится. После получения полного JSON
  объекты появляются порциями в редакторе, на кнопке AI виден счётчик. Модель не
  расставляет объекты во время размышления; схема показывает уже созданные объекты.
- **Stop** прекращает ожидание/применение. CLI может продолжать работу до таймаута.
  Уже добавленная часть остаётся одной записью undo. Выход из редактора останавливает
  задачу. Существующие объекты не удаляются и не перемещаются.
- **More** содержит настройки, аккаунт, историю и лимиты. Нажатие на статус моста
  повторяет проверку подключения. **More → Codex limits** показывает
  остаток лимитов подписки; **Geode → AI Builder → ChatGPT account** содержит вход
  и лимиты даже без открытого редактора.

## Вход через аккаунт ChatGPT, без API-ключей

Мост использует официальный **Codex CLI** с сохранённым входом в ChatGPT.
API-ключ не нужен и не запрашивается. Для Codex мост проверяет, что активен именно
вход ChatGPT, отключает наследование переменных API-ключей и не принимает вход
в режиме API key. Учётные данные остаются у официального CLI; в мод, логи моста
и репозиторий они не копируются.

На запущенном мосте откройте **Geode → AI Builder → ChatGPT account → Sign in
with ChatGPT**. Нажмите **Sign in**: прямо в моде появятся ссылка и одноразовый код.
**Copy code** копирует код, **Open link** открывает официальную страницу OpenAI.
Войдите в аккаунт в браузере, вставьте код и вернитесь в игру: статус обновится
автоматически. Пароль вводится только на официальной странице OpenAI.
Если вход CLI уже сохранён на ПК, повторный код не требуется. При необходимости
включите device-code login в настройках безопасности ChatGPT.
[Официальная документация входа](https://developers.openai.com/codex/auth/).

Доступ и лимиты Codex зависят от аккаунта/тарифа. Сессия может истечь или быть
отозвана; тогда повторите вход. Мост не обходит лимиты аккаунта.

## Мост на ПК

Нужны Python 3.10+ и Node.js LTS. Распакуйте **весь** Bridge.zip либо скачайте
исходники; `bridge.py`, `account_login.py`, `account_limits.py`, `chat_inputs.py` и `resources`
должны лежать рядом.
Зависимостей Python из pip у работающего моста нет.

```powershell
npm install -g @openai/codex
python bridge.py
```

Откройте `http://127.0.0.1:8765/login` или Sign in в моде. CLI-вариант входа:

```powershell
python bridge.py --login
python bridge.py --login --device-auth
python bridge.py --auth-status
```

Для телефона и моста на ПК в одной Wi-Fi сети:

```powershell
$env:BRIDGE_HOST = "0.0.0.0"
python bridge.py
```

Разрешите Python подключения в **частной** сети Windows. В Bridge URL на телефоне
укажите `http://<локальный-IP-ПК>:8765`. Не выставляйте мост в интернет: сетевой
авторизации между модом и мостом нет. По умолчанию он слушает только localhost.

## Android без Termux

Используйте мост на ПК по Wi-Fi, как описано выше. На телефоне нужны только Geode,
мод и браузер. В Geode задайте Bridge URL вашего ПК; вход, ссылка, код, статус и
лимиты доступны в настройках мода. В терминал на телефоне заходить не нужно.

**ПК и мост должны оставаться включёнными.** Отдельного официального Codex CLI,
встроенного в Android-мод, здесь нет. Мод не использует API-ключи, не извлекает
браузерные cookies и не подменяет официальную авторизацию. Вход в браузере телефона
авторизует официальный CLI на ПК, который показал этот код. Скрипт в `android/`
сохранён как необязательный старый вариант для пользователей Termux; для указанного
сценария он не нужен.

## Настройки

| Настройка | Значение |
| --- | --- |
| CLI | codex / claude / gemini; остальные CLI должны быть установлены и авторизованы отдельно |
| AI model | Пустое значение — модель CLI по умолчанию |
| ChatGPT account | Вход по ссылке/коду и оставшиеся лимиты |
| Bridge URL | Адрес устройства с мостом |
| Object limit | Любое неотрицательное целое в диапазоне 64-битной настройки; **0 = без лимита** |
| Object library | all — полный каталог; curated — классические ID ниже 1500 |
| Section length / Area height | Размер области только в режиме Extend |
| Difficulty | easy / normal / hard / demon |
| Decor density | low / medium / high |
| Allow mode changes | Разрешает порталы режимов, скорости, размера и гравитации |
| Avoid overlapping solid blocks | Предотвращает размещение новых solid-блоков в уже занятой ячейке |
| Objects per frame | Порция применения каждые 40 мс, по умолчанию 10 |
| Request timeout | Время ожидания, по умолчанию 180 секунд |
| AI reply language | auto / ru / en |
| Panel opacity | Непрозрачность фона |

Потолка 1500 объектов больше нет. Очень большие ответы ограничиваются реальными
возможностями CLI, таймаутом, памятью и производительностью устройства. «Без лимита»
не обещает бесконечную генерацию. Повышайте лимит и таймаут постепенно.

## Свобода генерации и проверки

В каталоге 3986 известных ID. Разрешены тройные шипы, порталы и смены режимов,
пады, орбы, пилы, блоки и разнообразный декор. Инструкции требуют связного маршрута,
сетки, понятных входов/выходов и цельной композиции вместо случайной россыпи блоков.
Нет общего запрета на сложные секции или сочетания препятствий.

Мод проверяет ID, конечные координаты, масштаб/поворот, дубликаты и выбранные
ограничения. В Decor фактический тип объекта дополнительно проверяется движком:
игровые препятствия не маскируются под декорации. Неподдерживаемые движком ID
пропускаются. Формат сейчас передаёт ID, позицию, поворот и масштаб: размещение
триггера само по себе **не настраивает** его группы, события и прочие параметры.

Каталог ID/имён: [GD Info Explorer](https://flowvix.github.io/gd-info-explorer/ids).
Имена — подсказка, проверка фактических размеров/типа выполняется в игре.
Шрифт русского ввода/ответов: Noto Sans, SIL OFL 1.1; лицензия включена в пакет.
Штатный Pusab берётся из игры, не распространяется в архиве мода.

```sh
python -m unittest discover -s tests -v
```

`GET /health` проверяет мост. При ошибке CLI проверьте вход, установленную команду,
лимиты аккаунта и терминальный лог. Логи ярлыка Android: `~/.cache/ai-builder/bridge.log`.

## Что не подтверждается компиляцией

Кнопка **Limits** в панели показывает остаток лимитов Codex вашего ChatGPT-аккаунта и время
их сброса в часовом поясе устройства. Это общие лимиты аккаунта, включая другие
сеансы Codex, а не обещанное число генераций и не лимиты переписки на сайте ChatGPT.
Мост читает их через официальный
локальный Codex CLI, без API-ключей. Данные кешируются на 60 секунд. Если CLI или
аккаунт не отдаёт лимиты, выводится **Limits unavailable**. Обновите также мост:
старый bridge.py не поддерживает `GET /limits`.

Сборки и тесты не доказывают проходимость. Нужны проверки в реальной игре:
сенсорный ввод/IME, перетаскивание, русский текст, большие порции, undo/redo,
сохранение уровня, реальные переходы между режимами и качество композиции.
Не обещается автоматическая проверка физики или художественное качество каждого
ответа. При сбое пришлите описание, запрос и лог Geode из `geode/logs` / `geode/crashlogs`.
